# Security Policy

## Reporting a vulnerability

If you discover a security vulnerability, please do **not** open a public issue.

Instead, report it privately to project maintainers with:

- vulnerability description
- potential impact
- affected versions / commit SHA
- reproduction details or proof of concept
- suggested remediation (if available)

Please include redacted logs only, and never send plaintext credentials.

## Response expectations

Maintainers will:

1. acknowledge receipt
2. triage severity and impact
3. provide remediation guidance and timeline when possible

## Disclosure

Please allow maintainers time to investigate and release a fix before public
disclosure.
